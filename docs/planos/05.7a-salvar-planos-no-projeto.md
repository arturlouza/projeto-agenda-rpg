# Plano: configuração antes da etapa 5.8

## Contexto

Os planos do Claude Code hoje ficam fora do projeto (`~/.claude/plans`). A ideia é passar a salvá-los em `docs/planos`. Além disso, o `.gitignore` deve ignorar as configurações locais do Claude Code e dois arquivos que o Windows gera sozinho. Nenhum código muda.

## Alterações (só estes dois arquivos)

### 1. Criar `.claude/settings.json`

```json
{
  "plansDirectory": "./docs/planos"
}
```

A pasta `.claude` ainda não existe e será criada junto com o arquivo. Este arquivo não fica ignorado, então entra no Git quando você fizer o commit.

### 2. Acrescentar ao final do `.gitignore`

```gitignore

# Configurações pessoais do Claude Code nesta máquina: não valem para o projeto
.claude/settings.local.json

# Miniaturas de imagens que o Windows cria sozinho dentro das pastas
Thumbs.db

# Preferências de exibição de pasta que o Windows cria sozinho
desktop.ini
```

As linhas que já existem não mudam.

## Pontos para você saber

- **`Thumbs.db` já estava ignorado por acidente:** a regra `*.db` (linha 12) também pega esse arquivo. A linha nova é redundante hoje, mas deixa a intenção explícita e continua valendo se a regra `*.db` mudar.
- **Os planos serão versionados:** `docs/planos` não fica ignorada, então os planos salvos lá aparecem no `git status` e entram no Git se você os adicionar.
- **`docs/planos` não será criada agora:** você pediu só esses dois arquivos, e o Git não guarda pasta vazia. Ela deve surgir quando o primeiro plano for salvo; isso será conferido no teste abaixo.
- **Este plano fica na pasta antiga:** a configuração só passa a valer depois de criada, e pode exigir uma sessão nova do Claude Code.

## Como testar

Na raiz do projeto, no PowerShell:

```powershell
# mostra qual regra ignora cada arquivo
git check-ignore -v .claude/settings.local.json Thumbs.db desktop.ini

# deve listar .gitignore como modificado e .claude/ como nova
git status

# não deve mostrar nada, porque este arquivo precisa entrar no Git
git check-ignore -v .claude/settings.json
```

Depois, abra uma sessão nova do Claude Code e peça o plano da etapa 5.8: o arquivo deve aparecer em `docs/planos`.
